Política de Privacidade

Última atualização: Agosto de 2026

📋 Introdução

O aplicativo Tarefa & Mesada ("nós", "nosso") é um app de gestão de tarefas e mesada para famílias. Esta política explica de forma clara e transparente quais dados coletamos, como os usamos e como você pode exercer seus direitos.

Ao usar o aplicativo, você concorda com as práticas descritas nesta política.

📊 Dados que Coletamos

Coletamos apenas os dados estritamente necessários para o funcionamento do app:

Dados de Cadastro (Pais/Responsáveis)

Dado Finalidade Obrigatório
Nome Identificação no app Sim
E-mail Login e recuperação de conta Sim
Senha (hash) Autenticação segura Sim (login por e-mail)
Google ID Login com Google Apenas se usar Login Google

Dados dos Filhos

Dado Finalidade Obrigatório
Nome (apelido) Identificação no app Sim
PIN (4 dígitos) Login simplificado Sim
Valor da mesada base Cálculo de mesada Não

Dados de Uso

  • Tarefas criadas, executadas e aprovadas
  • Recompensas criadas e resgatadas
  • Relatórios mensais de mesada
  • Token de push notification (para notificações)

O que NÃO coletamos: Localização, contatos, fotos, microfone, câmera, dados financeiros reais (contas bancárias, cartões), dados de navegação, cookies de rastreamento ou qualquer informação de terceiros.

🔐 Como Protegemos seus Dados

  • Senhas são armazenadas com hash bcrypt (nunca em texto puro)
  • Comunicação criptografada via HTTPS/TLS
  • Tokens de acesso (JWT) com expiração curta de 15 minutos
  • Banco de dados PostgreSQL gerenciado com SSL obrigatório
  • Tokens do Google validados com verificação de assinatura e audience

🎯 Como Usamos seus Dados

Seus dados são usados exclusivamente para:

  • Autenticar seu acesso ao aplicativo
  • Gerenciar tarefas, execuções e recompensas da sua família
  • Calcular relatórios mensais de mesada
  • Enviar notificações push sobre aprovações e resgates

Jamais vendemos, alugamos ou compartilhamos seus dados pessoais com terceiros para fins comerciais, publicitários ou de marketing.

🤝 Compartilhamento com Terceiros

Utilizamos os seguintes serviços de infraestrutura:

Serviço Finalidade Dados compartilhados
Supabase Banco de dados Todos os dados do app (criptografados)
Render.com Servidor da API Processamento de requisições
Google OAuth Login Social E-mail e nome (do Google)
Expo Push Notificações Token do dispositivo + mensagem

Nenhum desses serviços tem acesso aos seus dados para fins próprios.

👶 Privacidade de Crianças

O app é destinado ao uso familiar, onde pais/responsáveis são os administradores da conta. Crianças acessam o app exclusivamente através de um PIN fornecido pelo responsável.

Não coletamos dados pessoais de crianças além do nome (apelido) e PIN cadastrados pelo responsável. Não exigimos e-mail ou qualquer dado pessoal diretamente das crianças.

⚖️ Seus Direitos

De acordo com a Lei Geral de Proteção de Dados (LGPD — Lei 13.709/2018), você tem direito a:

  • Acessar seus dados pessoais a qualquer momento pelo app
  • Corrigir dados desatualizados ou incorretos
  • Excluir sua conta e todos os dados associados
  • Revogar o consentimento para uso dos dados
  • Solicitar portabilidade dos seus dados

Para exercer qualquer desses direitos, entre em contato pelo e-mail abaixo. Responderemos em até 15 dias úteis.

🗑️ Exclusão de Dados

Você pode solicitar a exclusão completa da sua conta e de todos os dados associados (incluindo dados dos filhos vinculados) a qualquer momento. Para isso, envie um e-mail para o endereço abaixo com o assunto "Exclusão de Conta".

Após a solicitação, seus dados serão permanentemente removidos em até 30 dias.

🔄 Alterações nesta Política

Podemos atualizar esta política periodicamente. Mudanças significativas serão comunicadas pelo app. A data da última atualização está no topo desta página.
